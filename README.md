# EV Charging Station Analytics Dashboard

## Project Overview
Developed an interactive dashboard using Microsoft Excel
to analyze EV charging station performance, revenue,
energy consumption, and charging sessions.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Interactive Slicers
- Data Visualization

## Key Performance Indicators
- Total Charging Sessions
- Total Energy Delivered
- Total Revenue
- Average Charging Duration
- Average Station Utilization

## Key Analysis
- Top 5 and Bottom 5 Stations by Revenue
- Revenue by City
- Revenue by Vehicle Type
- Energy Delivered by Charger Type
- Revenue by Payment Mode
- Monthly Revenue Trend
- Charging Session Status Analysis

## Interactive Features
Interactive slicers allow users to filter the dashboard
by city, charger type, vehicle type, station type,
and payment mode.

## Project Objective
To analyze EV charging data and present useful insights
through an interactive Excel dashboard.
